## Ограничения данных

### 1. Низкий локальный объём (регион 970)

11 из 12 seeds с регионом **970** вернули «нет данных» или единичные показы. Это **не ошибка MCP**, а реальное отражение нишевости водовоза в Wordstat по Новороссийску.

**Следствие:** частотности P0-кластеров CL01/CL02 частично опираются на край 10995.

### 2. Обрезка длинных ответов MCP

Для seeds «водовоз», «техническая вода», «вода водовоз» API вернул «… и ещё N запросов». В `03-wordstat-raw.csv` записаны **только видимые строки** с пометкой `truncated_response_*` в notes.

**Следствие:** хвост long-tail недосчитан; для micro-niche это некритично.

### 3. DEVICE_ALL недоступен

Параметр `DEVICE_ALL` вернул ошибку API. Все вызовы выполнены с `devices: ["all"]`.

### 4. SERP не проверялся

Все кластеры: `serp_check_status=not_checked`. URL-map и приоритеты — **рабочая гипотеза**, не финальная структура сайта.

### 5. Нет GSC / Яндекс.Вебмастер

Реальные запросы с сайта не учтены. После запуска prod — подключить и пересобрать ядро.

### 6. Конкуренция с 19л в одном seed

Seed «доставка воды новороссийск» даёт 701 показ, но ~70% связанных запросов — **19 литров** (исключены). Реальный addressable demand для водовоза — доля неизвестна без SERP.

## Качество очистки

**Исключали:**
- 19 л, бренды бутылей
- другие города (СПб, Москва, Сочи, Донецk…)
- вакансии («работа»)
- учебные/химические запросы по «техническая вода»
- конкурентные бренды (Весёлый водовоз, Алексей водовоз)
- отзывы (не primary landing)

**Риск ложного exclude:** «новороссийск доставка воды на дом» (64) — excluded as bottle-adjacent; возможен целевой long-tail для ёмкостей — **проверить в SERP**.

1. **Каннибализация с бутылочной выдачей** по head-запросу «доставка воды новороссийск»
2. **Завышение спроса** при использовании частот края вместо 970
