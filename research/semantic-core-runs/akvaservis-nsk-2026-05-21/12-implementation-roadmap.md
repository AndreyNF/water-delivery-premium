# 12. Roadmap внедрения

## Обзор

Один лендинг на `akvaservis-nsk.ru` закрывает 10 кластеров через якорные секции. Фокус: **отличить водовоз 7,5+ м³ от бутылочной выдачи** и закрыть коммерческий спрос по краю с локальной геопривязкой.

---

## 7 дней — быстрые победы (P0)

| День | Задача | Роль | KPI |
|---|---|---|---|
| 1 | Prod-телефон + WhatsApp на всех CTA | разработчик | 100% блоков |
| 1–2 | Title, meta description, H1 (бриф B01) | SEO + редактор | CTR в Вебмастере (baseline) |
| 2–3 | Блок «водовоз vs 19 л» + абзац про 7,5 м³ | редактор | ↓ bounce с нецелевого трафика |
| 3–4 | Новый блок «Техническая вода» (#services-technical) | разработчик + редактор | Покрытие CL05 |
| 4–5 | LocalBusiness + FAQPage JSON-LD | разработчик | Rich results test |
| 5–7 | Ручная SERP-проверка 3 запросов + правки title | SEO | Зафиксировать конкурентов |

**Результат 7 дней:** лендинг готов к индексации prod с корректным позиционированием.

---

## 30 дней — рост и измерение (P0 + P1)

| Неделя | Задача | Роль |
|---|---|---|
| 1 | Яндекс.Вебмастер, Метрика, цели на WhatsApp/звонок | аналитик |
| 2 | Раскрыть FAQ (6+ ответов), усилить стройка/бассейн/дом | редактор |
| 2 | Добавить вилку цен или «от X ₽ за 7,5 м³» если возможно | владелец + редактор |
| 3 | Фото водовозов, сертификаты на сайт | владелец |
| 4 | Анализ Search Console / Wordstat: первый пересмотр кластеров | SEO |

**KPI 30 дней:**
- Индексация главной в Яндексе
- Первые переходы по «водовоз»/«водовоз новороссийск»
- Конверсия в WhatsApp/звонок (baseline)

## 90 дней — масштабирование (P1 + P2)

| Месяц | Задача | Роль |
|---|---|---|
| 2 | Контент-кейсы: стройка, бассейн, частный дом (по 1 блоку) | редактор + владелец |
| 2 | B2B: пожарный резерв, промышленность — отдельные абзацы + форма | редактор |
| 3 | Решение по отдельному URL `/vodovoz/` на основе SERP + GSC | SEO |
| 3 | Повторный Wordstat-прогон + обновление CSV | SEO |
| 3 | A/B title с «от 7,5 м³» vs «водовоз 10 кубов» | SEO + аналитик |

**KPI 90 дней:**
- Топ-10 по «водовоз новороссийск» (реалистичная цель при low volume)
- Стабильные лиды с organic
- Снижение нецелевых звонков «19 литров»

## Риски roadmap

| Риск | Митигация |
|---|---|
| SERP по head — только 19л | Anti-bottle блок, long-tail «водовоз» |
| Нет данных 970 | Локальный SEO: карты, районы, телефон |
| Нет прайса | FAQ + быстрый расчёт в WhatsApp |
| Мало контента для «техническая вода» | Определение + коммерческий CTA, не статья-энциклопедия |
