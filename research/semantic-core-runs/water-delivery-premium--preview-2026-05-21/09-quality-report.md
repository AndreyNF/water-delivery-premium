## Ограничения

1. **Низкий локальный объём водовоза** — «водовоз новороссийск» 13 показов/мес в 970 (proxy 10995: 22). Выводы опираются на смежные запросы и proxy по краю.
2. **SERP не проверен** — все кластеры `serp_check_status=not_checked`. Интенты назначены вручную.
3. **Конкуренция с 19л** — «доставка воды новороссийск» 568/mo (970), ~70% запросов — бутыли (исключены из ядра).
4. **Preview vs prod** — осмотрен preview; **телефон на preview placeholder +7 (988) 000-00-00**, prod-цель +7 988 317-44-84.
5. **Proxy 10995** — не заменяет 970 для локального таргетинга; используется для валидации масштаба ниши.
6. **Нет GSC/Вебмастер** — нет данных о реальных показах/CTR.
